# PixelFoundry IDE v1.1.0 — 中转站一键适配 + IDE / 画布布局重做

本次更新把「配置各种中转站 API」这件最劝退的事做到了接近一键，同时重做了 IDE 与独立画布的布局，
并修掉两个卡流程的真实 bug。

---

## 🔌 中转站（relay）API：从"填一堆 JSON 路径试错"到"点一下"

- **一键适配端点…**：填好 Base URL + Key 后点一下，自动探测该服务实际支持的**视频提交端点**
  （16 条常见路径），给出结果表（路径 / GET / POST / 说明），推荐行一点即写回**提交端点 + 轮询端点 + 服务商适配**。
  - **默认只发无害 GET**（不会创建任务、不计费）；想要更确定可手动点「用 POST 再探测一次…」（带醒目警告）。
  - 判定依据：`404 / Invalid URL / not found` = 路径不存在；`400 / 422` = 路径存在只是请求不对；
    `401 / 403` = 路径存在、鉴权问题（提示去检查「鉴权方式」）。
  - **POST-only 端点也能被识别**：GET 返回 405 说明路径存在、只是不接受 GET（中转站很常见），会作为候选推荐。
- **Base URL 自动规整**：把文档里的完整地址整条粘进来也没关系 ——
  `https://relay.example.com/v1/videos/image2video` 会自动拆成 base `…/v1` + 端点 `/videos/image2video`，
  并明确告诉你拆了什么。缺协议头、末尾斜杠、查询参数都会处理。
- **从 curl 导入…**：粘贴浏览器「Copy as cURL」，自动填好 Base URL / 提交端点 / 方法 / 请求头 / 请求体模板。
- **预览请求 / 测试并检测字段**：前者零网络、直接看将发出的请求（Key 打码）；后者真发一次提交，
  失败也显示原始响应，并自动识别**任务 ID / 状态 / 视频 URL** 的字段路径，点「使用」即写入配置。
- **鉴权方式 6 选 1**（三类 API 通用）：Bearer / `X-API-Key` / `api-key` / URL 查询参数 / 自定义头名+前缀 / 不鉴权。
- **视频请求体模板占位符扩到 15 个**：`$image` `$image_raw` `$image_url` `$last_image` `$negative_prompt`
  `$seed` `$ratio` `$resolution` `$mode` `$frames` `$fps` `$duration` `$model` `$prompt`，轮询体另有 `$task_id`；
  值做 JSON 转义（提示词带引号/换行不再破坏模板）。提交方法支持 POST/PUT/GET，轮询请求体可单独配。
- 新增预设「中转站：一键适配端点」；可灵预设标注清楚「直连需 JWT、经中转用 Bearer Key，路径是可灵专有」。
- 视频 404 / `Invalid URL` 的报错现在直接指向「一键适配端点…」与「从 curl 导入…」。
- 修复 `$image` 会抢先匹配 `$image_url` / `$image_raw` 的前缀冲突 bug。
- 完整说明见 **[docs/api_setup.md](https://github.com/xf785/PixelFoundry-IDE/blob/main/docs/api_setup.md)**。

## 🎬 IDE 模式：布局重做 + 两个卡流程的 bug

- **顶部步骤条**：6 个步骤平铺一行，`✓ 已完成 / ▶ 当前 / ○ 未开始` 一眼看清进度，点一下即切换；
  右侧是当前步骤的主执行按钮；每步成功后自动打勾并提示「下一步」。
- **三栏布局**：左「资源」（项目 + 参考图 / 首帧图）| 中「预览 / 编辑 / 提示词」+ **时间轴就在画面正下方** |
  右「参数」+「日志」。参数面板改为**默认展开**（旧版默认整栏收起，进 IDE 几乎看不到参数）。
- **修掉「生图后无法加入序列帧」**：时间轴新增「**+ 当前图**」；帧序列为空时**编辑器直接打开首帧图**编辑
  （旧版是空白画布，看起来像图片丢了），编辑结果会写回首帧。
- **修掉「首帧生成视频」卡住**：新增「**用当前帧作为首帧**」与首帧缩略图/尺寸状态；没有单独设首帧时，
  动画步骤会**自动回退到帧序列第 1 帧**并在日志说明，而不是报错。
- 布局持久化扩展到三栏宽度、中栏上下比例与两侧收起状态，病态布局自动回退。

- 修掉一处隐藏问题：统计/范围提示禁止换行会把资源栏撑住拖不窄，现已恢复换行。

## 📦 下载与运行（Windows x64）

1. 下载 `PixelFoundry-v1.1.0-win64.zip` 并解压到任意目录（建议路径不含中文/空格）。
2. 双击目录里的 **`PixelFoundry.exe`** 启动。
3. 首次启动可直接用**模拟 API 离线体验**：设置 → 勾选「使用模拟 API（无密钥）」。

> 绿色免安装：不写注册表，配置与密钥保存在 `%APPDATA%\PixelFoundry`（API Key 用 Fernet 加密落盘）。
> 压缩包内已包含 Python 运行时与全部依赖（含 ffmpeg），无需安装 Python。

### 从源码运行

```bash
git clone https://github.com/xf785/PixelFoundry-IDE.git
cd PixelFoundry-IDE
python -m venv .venv
.\.venv\Scripts\activate        # Windows
pip install -r requirements.txt
python main.py
python main.py --demo           # 无需 API Key 的演示模式
```

## ⚠️ 已知限制

- 图转视频质量依赖服务商，动作幅度可能偏小，可用「播放倍速」或增加帧数改善。
- 非像素风图片会被像素化流程判定后跳过完美像素，改走缩放 + 量化。
- 超大分辨率帧序列处理较慢（未做大图性能优化）。
- 「一键适配端点」默认只发 GET，因此个别"只接受 POST 且 GET 返回 404"的服务需要手动点一次 POST 复探。

# PixelFoundry IDE v1.1.0 — one-click relay setup + rebuilt IDE / canvas layouts

This release makes configuring relay (aggregator) APIs nearly one-click, rebuilds the IDE and standalone
canvas layouts, and fixes two bugs that could block the pipeline.

## 🔌 Relay-friendly API setup

- **One-click endpoint adapt**: with Base URL + key filled in, probe which **video submit endpoint** the
  service actually serves (16 common paths) and get a table (path / GET / POST / note); one click writes
  back the submit URL, poll URL and provider adapter.
  - **Only harmless GETs by default** (no task created, no billing); POST re-probing is a separate manual
    button with a clear warning.
  - Classification: `404 / Invalid URL / not found` → path missing; `400 / 422` → path exists, request
    rejected; `401 / 403` → path exists, auth problem (points at the auth-style setting).
  - **POST-only endpoints are detected too**: a `405` on GET means the path exists but rejects GET
    (common on relays).
- **Automatic Base URL normalisation**: pasting a full endpoint URL is fine —
  `https://relay.example.com/v1/videos/image2video` is split into base `…/v1` + endpoint
  `/videos/image2video`, and the app tells you exactly what it moved.
- **Import from cURL**: paste “Copy as cURL” from the browser and the base URL, submit endpoint, method,
  headers and body template are filled in for you.
- **Preview request / Test & detect fields**: the former shows the exact request with the key redacted and
  no network call; the latter performs one submit, shows the raw response even on failure, and
  auto-detects the task-id / status / video-URL paths for one-click apply.
- **Six auth styles** for all three API kinds: Bearer / `X-API-Key` / `api-key` / query param /
  custom header + prefix / none.
- **15 body-template placeholders** (`$image`, `$image_raw`, `$image_url`, `$last_image`,
  `$negative_prompt`, `$seed`, `$ratio`, `$resolution`, `$mode`, `$frames`, `$fps`, `$duration`,
  `$model`, `$prompt`, plus `$task_id` for the poll body), JSON-escaped; POST/PUT/GET submit and a
  separate poll body template.
- New “Relay: one-click endpoint adapt” preset; the Kling preset now states that its path is
  Kling-specific (JWT when calling the vendor directly, Bearer key via a relay).
- Video 404 / `Invalid URL` errors now point straight at **One-click endpoint adapt** and **Import from cURL**.
- Fixed a prefix collision where `$image` swallowed `$image_url` / `$image_raw`.

## 🎬 IDE mode

- **Top step bar**: the six steps on one row as `✓ done / ▶ current / ○ pending` with one-click switching
  and the primary run button on the right; each successful step ticks itself and suggests the next.
- **Three columns**: Assets (project + reference / first frame) | Preview / Edit / Prompts with the
  **timeline right underneath** | Parameters + Log. Parameters are **expanded by default** now.
- **Fixed “cannot add the generated image to the frame list”**: a new **+ Current image** button, and while
  the sequence is empty the editor opens the first frame itself instead of a blank canvas.
- **Fixed “first frame → video gets stuck”**: a **Use current frame as first frame** action plus a
  first-frame thumbnail; when no first frame is set the Animation step **falls back to frame 1** and says so.

## 🖼️ Standalone pixel canvas

- **Draggable sections inside the asset dock** (pack list / folder tree / thumbnails), removing the old
  hard height caps (78 px pack list, 220 px tree).
- Eight category buttons plus a separate search row collapsed into **one row (category dropdown +
  search)**, saving ~44 px of vertical space.
- The right dock went from three panels to two (preset + size on one row, background + *New canvas* on
  another, canvas info folded in).

## Other

- ~70 new English strings; three real i18n defects fixed (untranslated preset names, an
  `画面比例` / `宽高比` English collision, and registry-overwritten IDE status labels).
- Tests **600 → 700**; CI green on all four platform/Python combinations; `ruff` clean.

## 📦 Download & run (Windows x64)

1. Download `PixelFoundry-v1.1.0-win64.zip` and extract it anywhere (avoid non-ASCII/spaced paths).
2. Double-click **`PixelFoundry.exe`**.
3. Try it offline with the **mock API**: Settings → tick "Use mock API (no key)".

> Portable: no registry writes; config and keys live in `%APPDATA%\PixelFoundry` (API keys encrypted with
> Fernet). The zip bundles the Python runtime and all dependencies (including ffmpeg).

## ⚠️ Known limitations

- Image-to-video quality depends on the provider; raise the frame count or use the speed multiplier.
- Non-pixel-art images skip Perfect Pixel and fall back to resize + quantize.
- “One-click endpoint adapt” only sends GETs by default, so a rare “POST-only and 404 on GET” service
  needs one manual POST re-probe.
